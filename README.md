📦 Spring Boot Rate Limiter Service

A configurable, extensible rate limiter service built using Spring Boot.

📑 Features

    📖 Configurable via application.properties

    🛠️ Pluggable strategy implementations using the Strategy design pattern

    🌱 Built on Spring Boot with embedded Tomcat

    📦 Packaged as a fat JAR and Docker-ready

    📝 Clean separation of service, strategy, and config components

📌 Tech Stack

    Java 17+

    Spring Boot 3.x

    Embedded Tomcat

    Maven

🚀 How to Build & Run

📦 Build the fat JAR:

./mvnw clean package

🏃 Run the application:

java -jar target/rate-limiter-0.0.1-SNAPSHOT.jar
